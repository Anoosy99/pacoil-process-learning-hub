# PACOIL Process Learning Hub

An interactive, mobile-friendly training dashboard for learning the fundamentals of an industrial oil bleaching and filtration process.

## What it includes

- Simplified interactive bleaching-to-filtration process flow
- Equipment guide for pumps, valves, vessels and filters
- Temperature, pressure, flow and level explanations
- Interactive PV vs SV simulator
- Seven-stage filter-cycle trainer
- Alarm interpretation exercise
- Historical trend-reading example
- Daily checklist and notes saved locally in the browser

## Run locally

No installation or backend is required. Open `index.html` in a browser, or serve the folder with any static file server.

For example:

```bash
npx serve .
```

## Important

This is an educational simulation. It is not connected to any plant system and must not be used to operate equipment or replace authorised training and procedures.
